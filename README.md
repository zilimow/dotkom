# Mechanik

Приложение для учета ремонтов парка техники

## Функциональность

###  Журнал учета работ
- Добавление записей о работе техники
- Фильтрация по типу техники
- Поиск по модели и описанию работ
- Редактирование существующих записей

###  Справочник техники
- Регистрация новых единиц техники
- Хранение полной информации (VIN, двигатель, LinkOne)
- Поиск по бортовому номеру, VIN, модели
- Редактирование данных техники

## Установка и запуск

### Требования
- Python 3.9 или выше
- uv (рекомендуется) или pip

### Установка с uv
```bash
# Установка uv (если не установлен)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Установка зависимостей
uv sync

# Запуск приложения
uv run streamlit run app.py
